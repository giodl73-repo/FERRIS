# OSPREY Program Name Transition

OSPREY was the architecture code name used during the performance and Crates
Series research.

The selected public product is now **FERRIS Blueprint**. One engine is invoked
as `ferris blueprint` for complete application and cross-workspace scope and as
`cargo blueprint` through the `cargo-blueprint` package for current-workspace
adoption.

See the [Blueprint program](BLUEPRINT_PROGRAM.md).
