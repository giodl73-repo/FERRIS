# OSPREY Program Name Transition

OSPREY was the architecture code name used during the performance and Crates
Series research.

The selected public product is now **Ferris**. One engine is invoked as
`ferris` for complete application and cross-workspace scope and as
`cargo ferris` through the `cargo-ferris` package for current-workspace
adoption. Blueprint names the internal model and planning engine.

See the [Ferris program](FERRIS_PROGRAM.md) and
[Blueprint planning engine program](BLUEPRINT_PROGRAM.md).
