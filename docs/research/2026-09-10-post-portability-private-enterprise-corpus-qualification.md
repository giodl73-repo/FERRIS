# Post-Portability Private Enterprise-Shape Corpus Qualification

Date: 2026-09-10
Status: Complete
Decision: Accept as the primary deterministic regression and demonstration
suite for existing Ferris planning behavior

## Scope

One unchanged public Ferris product revision was evaluated against five exact
corrected private enterprise-shape synthetic corpus revisions. Public records
use only `EC-01` through `EC-05`; repository identities, revisions, paths,
executable and artifact hashes, run identities, raw output, and identifiable
timings remain in private custody.

This campaign is fresh evidence. Neither earlier incomplete qualification
attempt is counted toward its result.

## Findings

### FERRIS-ECQ-001: Owner integrity passed on both platforms

All five repository-owned integrity gates passed on local Windows and
GitHub-hosted Ubuntu. These gates retained ordinary Cargo, generated-corpus,
and repository-owner authority; Ferris did not replace or reinterpret them.

### FERRIS-ECQ-002: All declared scenarios matched on both platforms

Each platform completed the same 26 existing scenarios:

| Outcome | Windows | Hosted Ubuntu |
|---|---:|---:|
| Durable scenarios | 26 | 26 |
| Matched pass | 24 | 24 |
| Expected matched failure | 2 | 2 |
| Selected/full divergence | 0 | 0 |

Repeated plan, selection, federated, and typed-result identities remained
stable within each platform. Independent Cargo and application-graph oracles
matched Ferris selections and dispositions.

### FERRIS-ECQ-003: Conservative boundaries remained visible

Seven scenarios on each platform selected their declared conservative fallback
rather than narrowing. This is expected fail-closed behavior, not a failed
optimization. The result preserves unknown, unsupported, and broad-scope
conditions instead of converting them into narrow success-shaped output.

### FERRIS-ECQ-004: Maximum and typed controls held

Both federated maximum cases retained all 256 explicit inputs and three
input-order variants on both platforms. Each platform also reproduced three
typed rejections with stable diagnostics, process exits, and result identities;
none launched an owner command.

### FERRIS-ECQ-005: Qualification is deterministic, not production evidence

The five families now provide reproducible coverage for linear dependency,
fanout, fail-closed boundary, 96-package scale, and 16-workspace federated
shapes. They are accepted as the primary deterministic regression and
demonstration suite for the already-implemented planning surfaces.

They remain synthetic. This result does not establish production
representativeness, realized build-time reduction, cost savings, support
readiness, or permission to replace full owner checks with affected-only
execution.

## Custody and cleanup

Five temporary hosted-validation pull requests built the frozen public Ferris
revision and invoked unchanged owner and scenario contracts. Detailed artifacts
were retained privately. Every temporary pull request closed without merge,
every temporary local and remote branch was removed, and every private checkout
returned to its clean default branch.
