# ECOS-Q12: Ecosystem Intervention Decision

**Status:** Planned

**Area:** Program closeout

**Depends on:** ECOS-Q01 through ECOS-Q11

## Question

For each verified ecosystem gap, should FERRIUM document, adapt, standardize,
contribute upstream, steward, prototype, or defer?

## Starting hypothesis

Most gaps will favor evidence, compatibility tests, adapters, or upstream
stewardship over new foundational crates or a curated distribution.

## Decision informed

Close the Crates Series, define the OSPREY ecosystem model, and decide whether
any bounded ecosystem capability advances.

## Primary roles

All nine FERRIUM roles.
