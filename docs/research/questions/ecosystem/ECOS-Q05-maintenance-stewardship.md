# ECOS-Q05: Maintenance and Stewardship

**Status:** Complete

**Area:** Lifecycle

**Depends on:** ECOS-Q02

## Question

How can users detect maintainer concentration, stalled releases, ownership
transfer, forks, and abandonment?

## Starting hypothesis

Repository activity is insufficient; stewardship evidence needs owner,
release, review, succession, security-response, funding, and replacement
signals.

## Decision informed

Define the Crate Ecosystem Ledger's maintenance and stewardship fields.

## Primary roles

Rust Maintainer, Ecosystem Strategist, Native Platform Adopter.

## Decision

Adopt renewable, multidimensional stewardship evidence across registry
authority, publication provenance, source governance, crate-path work,
responsiveness, concentration, succession, lifecycle declarations, and
replacement lineage.

Release age, owner count, organization custody, funding, repository activity,
and review counts are signals rather than maintenance verdicts. Unmaintained
status requires an explicit declaration or contact-based evidence consistent
with RustSec policy.
