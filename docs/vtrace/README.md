# Ferris Go VTRACE

This directory connects the Ferris Go mission, product requirements, target
specification, implementation work packages, verification, validation,
evidence, and review decisions.

Ferris remains the product. VTRACE is coordination and traceability only; it
adds no `ferris` command, schema field, or runtime dependency.
