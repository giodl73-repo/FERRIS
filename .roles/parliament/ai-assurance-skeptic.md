# AI Assurance Skeptic

## Key question

*"What does the evidence establish, and what is the model merely asserting?"*

## Verify

- Generated work records source revision, model action, commands, and results.
- Tests address behavior rather than only compilation.
- Security, performance, and soundness claims require dedicated evidence.
- Failures remain visible instead of being converted into success-shaped output.
- Human approval boundaries are explicit for high-risk changes.
