# FERRIUM Pulse

## Workflow

1. Read `context/waves/PHASES.md`.
2. Read the active wave and target pulse.
3. Read relevant research notes and `.roles`.
4. Implement the smallest measurable slice.
5. Keep compiler evidence distinct from behavioral assurance.
6. Update docs, findings, limitations, and pulse status.
7. Run the pulse validation commands and `git diff --check`.
