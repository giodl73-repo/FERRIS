# FERRIUM Wave

Use this skill to create or update FERRIUM waves.

## Wave requirements

- State the systems-development gap and measurable decision.
- Require cited research before selecting a new capability lane.
- Identify affected crates, fixtures, tools, and candidate consumers.
- Keep shared contracts product-neutral.
- Break work into small pulses with concrete validation.
- Name relevant `.roles` reviewers and explicit non-goals.
