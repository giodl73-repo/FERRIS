# Pulse 06: Consumer-Root Repeatable Enterprise Onboarding

Status: Authorized
Implementation authority: One disposable evidence attempt only

## Objective

Complete the dependency-correct Pulse 05 protocol with execution commands
launched from the repository whose `.ferris/` records they consume.

## Authority

The pulse may set only the process working directory for each `go` and `verify`
invocation to the applicable disposable `EO-01` or `EO-02` root.

It otherwise inherits Pulse 05's exact Ferris and consumer revisions,
dependency-complete generator, root federated request, native PowerShell
staging, plans, Action Plans, owner commands, Windows and native-Linux scope,
stop conditions, removal invariant, cleanup, and exclusions.

## Success

Success requires four successful `go` invocations, four valid receipts,
complete removal of `.ferris/` and the `EO-02` root request, four passing
post-removal owner commands, exact clean consumer revisions, and complete
disposable cleanup.

Any failed gate stops the pulse without repair or retry. No product change,
persisted consumer change, performance claim, CI authority, production claim,
or support claim is authorized.
