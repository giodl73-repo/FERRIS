# Pulse 01: Corrected Five-Family Two-Platform Qualification

Status: Complete
Implementation authority: Evidence only
Budget: One complete Windows campaign and one complete hosted Ubuntu campaign;
no scenario retry

## User outcome

Determine whether the corrected five-family private enterprise-shape corpus can
serve as the primary deterministic current-Ferris regression and demonstration
suite for the already-implemented planning surfaces.

## Inputs

- frozen unchanged Ferris product revision and platform executable hashes;
- corrected immutable private default-branch revisions;
- existing corpus owner-integrity checks and scenario runners;
- existing independent Cargo and application-graph oracles; and
- existing selected/full and typed-failure expectations.

Exact private bindings remain in private custody.

## Procedure

1. Freeze all revisions and toolchain identities.
2. Run owner-integrity gates on Windows.
3. Run every existing Windows scenario once without retry.
4. Create temporary private hosted-validation branches containing only the
   adapter needed to build frozen Ferris and invoke those same owner gates and
   scenarios.
5. Run owner-integrity gates and every existing scenario on hosted Ubuntu.
6. Retain detailed evidence privately.
7. Remove all temporary hosted-validation branches after custody.
8. Publish aggregate results and all role dispositions.

## Acceptance criteria

- every owner-integrity check passes on both platforms;
- every expected selection, fallback, relationship disposition, and typed
  rejection matches;
- repeated identities remain stable within each platform;
- selected/full outcomes match, including declared failure controls;
- both federated maximum cases retain all 256 inputs;
- no rejected request launches owner work;
- all temporary branches are removed; and
- no private identity or identifiable measurement enters public evidence.

Any owner-integrity, planning, oracle, selected/full, typed-result, privacy, or
cleanup failure closes this pulse without product-fix authority.

## Result

The fresh campaign passed on local Windows and GitHub-hosted Ubuntu.

On each platform:

- all five owner-integrity gates passed;
- all 26 existing scenarios produced durable evidence;
- 24 scenarios were `matched-pass`;
- the two declared scale and federated failure controls were
  `matched-failure`;
- seven scenarios used their expected conservative fallback;
- repeated plan, selection, federated, and typed-result identities were stable;
- no selected-pass/full-fail or other selected/full divergence occurred;
- both federated maximum cases preserved all 256 inputs and three input-order
  variants; and
- all three typed federated rejections matched their expected diagnostics and
  exit codes while executing zero owner commands.

The five temporary hosted-validation pull requests closed without merge after
private evidence custody. Their local and remote branches were removed, and
all five private checkouts returned to clean default branches.

The public aggregate report is
[`Post-portability private enterprise-shape corpus qualification`](../../../../docs/research/2026-09-10-post-portability-private-enterprise-corpus-qualification.md).
Exact repository bindings, revisions, executable and artifact hashes, run
identities, raw output, and timings remain in private custody.
