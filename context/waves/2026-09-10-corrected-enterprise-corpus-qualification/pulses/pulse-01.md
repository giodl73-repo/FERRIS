# Pulse 01: Corrected Five-Family Qualification

Status: Complete; stopped incomplete during Windows federated execution
Implementation authority: Evidence only
Budget: One complete Windows campaign and one complete hosted Ubuntu campaign;
no scenario retry

## User outcome

Determine whether the corrected five-family private enterprise-shape corpus can
serve as the primary current-Ferris regression and demonstration suite for the
already-implemented planning surfaces.

## Inputs

- frozen Ferris product revision and executable hash;
- corrected immutable private default-branch revisions;
- existing corpus owner-integrity checks and scenario runners;
- existing independent Cargo and application-graph oracles; and
- existing selected/full and typed-failure expectations.

Exact private bindings remain in private custody.

## Procedure

1. Freeze all revisions and toolchain identities.
2. Run owner-integrity gates on Windows.
3. Run every existing Windows scenario without retry.
4. Create temporary private hosted-validation branches containing only the
   execution adapter needed to invoke those same scenarios.
5. Run owner-integrity gates and every existing scenario on hosted Ubuntu.
6. Retain detailed evidence privately.
7. Remove temporary hosted-validation branches after custody.
8. Publish aggregate results and all role dispositions.

## Acceptance criteria

- every owner-integrity check passes;
- every expected selection, fallback, relationship disposition, and typed
  rejection matches;
- repeated identities remain stable within each platform;
- selected/full outcomes match, including declared failure controls;
- no rejected request launches owner work;
- all temporary branches are removed; and
- no private identity or identifiable measurement enters public evidence.

Any owner-integrity, planning, oracle, selected/full, typed-result, privacy, or
cleanup failure closes this pulse without product-fix authority.

## Result

The corrected Windows owner-integrity gate passed for all five families.

The three small-workspace families retained 11 complete scenario records:

- 11 stable two-pass plan and selection identities;
- six narrowed selections and five conservative full-workspace fallbacks; and
- 11 matched-pass selected/full outcomes.

The high-cardinality family retained six complete scenario records:

- six stable two-pass plan and selection identities;
- five matched-pass outcomes;
- one declared matched-failure outcome; and
- one conservative full-workspace fallback.

The federated runner executed from a long private custody root. When it reached
the existing maximum-input case, its 256 absolute changed-path arguments
exceeded the Windows process command-line limit before the Ferris process
launched. The runner writes its evidence only after the complete matrix, so no
federated scenario has a durable structured record from this attempt. Earlier
in-memory activity is classified `not observed`, not passed.

The stop condition ended the pulse without retry:

- 17 Windows scenario records are retained;
- 16 are `matched-pass`;
- one is the expected `matched-failure`;
- six require conservative fallback;
- no selected-pass/full-fail divergence appears in retained evidence;
- no hosted-validation branch was created; and
- hosted Ubuntu was not attempted.
