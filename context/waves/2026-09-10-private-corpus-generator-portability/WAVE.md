# Wave: Private Corpus Generator Portability

Status: Complete; Pulse 01 passed
Implementation authority: One private owner-tooling correction
Successor authority: None

## Systems-development gap

The private enterprise-corpus qualification stopped before Ferris execution
because `EC-04` passed formatting, Clippy, and all 96 package tests but failed
its repository-owned generated-topology integrity check on Windows. The
checked-in topology and a fresh generator result were not byte-identical.

The measurable decision is whether one bounded owner-side serialization fix can
make the existing generated corpus reproduce byte-for-byte on Windows and
hosted Ubuntu without changing its semantic topology or any Ferris behavior.

- a Ferris product, schema, dependency, or command change;

- suppressing or weakening byte comparison;
- a second corrective approach;
- another private repository; or
- merging the private pull request without separate user direction.
