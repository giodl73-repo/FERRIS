Input limits, metadata and originals

Native limits: 1 MiB per UTF-8 input and 10,000 changes. Browser admission adds 24 nested containers, a combined 2 MiB leaf-path budget, 4 MiB reports, and 64 MiB WASM memory. These are resource limits, not changes to the native evidence contract. A refused request produces no partial comparison.

Profile IDs, revisions, consumers and object keys are output-visible metadata; do not put secrets in those fields. Raw section values are omitted from comparison reports. Opening a file preserves its original UTF-8 bytes, including BOM/CRLF. The editor displays LF; inspection/current download retain loaded text until editing. Editing uses the editor's LF text. Use an LF copy explicitly to remove a leading BOM and normalize CRLF/CR. Original downloads remain separate, even after edits or examples.
